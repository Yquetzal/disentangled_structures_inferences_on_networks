# Accompanying paper

Guilhem Dupuy and Rémy Cazabet. *Beyond the Dominant Meso-Scale Structure:
Scalable Mixed Models for Interpretable Network Analysis.* Manuscript.

The paper describes how to model a known source of network connectivity and
analyse the additional structure through communities and embeddings. It presents
the methods, synthetic benchmarks and applications implemented in this library.
